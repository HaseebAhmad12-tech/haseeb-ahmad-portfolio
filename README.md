# Haseeb Ahmad — Portfolio

A premium, responsive static portfolio for Haseeb Ahmad, CRM Consultant at Systems Limited.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your real email.
2. When the CV becomes available, update Experience, Education, Certifications and exact Skills/Projects.
3. Replace the LinkedIn placeholder URL with your LinkedIn profile.
4. Review project wording to ensure no confidential client information is included.

## Run locally
Open `index.html` in a browser.

## Deploy free on Netlify
- Create a GitHub repository and upload these three files.
- In Netlify, choose Add new project → Import an existing project → GitHub.
- Select the repository and deploy.
- Netlify will provide a free `*.netlify.app` address.
